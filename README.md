# ChitraMitra

ChitraMitra is an India-first, multilingual printable learning platform for children ages 3–8.

## Frozen V1
- 6 launch languages: English, Telugu, Hindi, Tamil, Kannada, Malayalam
- 20 priority topics
- 5 launch formats: charts, worksheets, colouring, tracing, flashcards
- 600 structured resource combinations (6 languages × 20 topics × 5 formats)
- Search and filters by language, age, topic and format
- Resource preview, A4 browser print and Save-as-PDF flow
- Language switching and related resources
- Static-first, mobile-first, no mandatory accounts, no child personal data
- SEO metadata, canonical URLs, JSON-LD, sitemap and robots.txt

The V1 stop rule is intentional: once these completion checks pass, do not add accounts, payments, ads as a core feature, native apps, AI generation, audio platforms, or other V2 scope.
